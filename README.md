# IGR AUTO SALES

Modern MVP frontend for a Florida independent auto dealership and rental business.

Tech stack: Next.js 14 (App Router), React, TypeScript, Tailwind CSS, Framer Motion, react-icons.

Quick start:

```bash
cd EagleVisionEdge
npm install
npm run dev
```

Open http://localhost:3000

Project structure highlights:
- app/ - Next.js App Router pages
- components/ - Reusable UI components
- data/ - Mock JSON/TS data
- types/ - TypeScript type definitions
- styles/ - Tailwind globals

This is a frontend-only MVP with mock data to demo to dealership owners.
